## Notes for Claude

- In Claude Code, you can run the scripts and read `reports/` and the tracker directly. Adding the day's
  qualifying jobs with `tools/add_to_tracker.py` and filling in Resume Match and Assistant Notes is part of the
  daily routine. Ask before any other edit, never write in the person's Notes column, and back up first.
- In a claude.ai chat or Project, the person can upload `AGENTS.md` (or add it to Project knowledge) along with
  their tracker, resume and daily report. Guide them to run commands on their computer.
- A ready-made skill is in `skills/job-search-assistant/`. People can install it so any Claude conversation
  knows how to help with this project.
